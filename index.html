Fundamentos Modernos de ECMAScript (ES6+)

Sintaxis indispensable para escribir componentes y funciones puras.

1

const vs let (Cero var)

Scope de bloque { } y erradicación del hoisting. En React el 90% de variables son const.

const FICHA = '3314621';
let contador = 0;
2

Funciones Flecha (Arrow Functions)

Retorno implícito y contexto léxico de this para manejadores de eventos.

const saludar = (nombre) => `Hola, ${nombre}`;
3

Desestructuración (Destructuring)

Extracción limpia de propiedades en objetos (props) y arreglos (hooks useState).

const { nombre, rol } = aprendiz;
const [ estado, setEstado ] = useState(0);
4

Operador Spread / Rest (...)

Clonación inmutable y fusión de objetos de estado sin mutar referencias en memoria.

const nuevoObj = { ...usuario, activo: true };

Inmutabilidad en Arreglos y Objetos

Por qué en React jamás debes usar .push() ni modificar el estado directamente.

Métodos Mutables (Prohibidos en React)

Modifican el mismo puntero en memoria. React no detecta cambios y no actualiza el DOM.

items.push(nuevo); // ERROR GRAVE
items.splice(0, 1); // ERROR GRAVE
usuario.nombre = 'David'; // ERROR GRAVE
Métodos Inmutables (Obligatorios en React)

Generan un nuevo objeto o array en memoria. React compara con Object.is y renderiza de inmediato.

[...items, nuevo] // Agregar
items.filter(i => i.id !== id) // Eliminar
items.map(i => i.id === id ? {...i, activo: true} : i) // Modificar

Camino a React 19 + Vite

Conexión directa entre lo aprendido y el desarrollo de componentes modernos.

En JavaScript ES6+

Una función flecha que retorna HTML

const Tarjeta = ({ titulo }) => `<div>${titulo}</div>`;
En React + Vite

¡Es un Componente Funcional con JSX!

export const Tarjeta = ({ titulo }) => <div>{titulo}</div>;
